## 当前整体判断

正式 src 提供 SGLang/Ascend 原生观察、分层参数化模板、轻量控制和动态执行；节点耗时使用显式假设。旧成本与采样实现归档，当前没有实测性能模型或精度结论，多卡结构的扩大独立验收尚未完成。

同一模板库主要复用请求长度、成员、到达、并发与 KV 容量变化。不同模型、TP、dtype、attention backend 和 page_size 使用各自来源；这些是当前实现边界，不能写成理论上均无法变换。页大小跨库迁移尚未实现，控制/资源规则及局部物理分支仍各有适用条件。

已有结构证据来自旧补丁镜像：Qwen3-8B/BF16 TP1/2、Qwen3-32B/BF16 TP2/4/8、Llama-2-7B/FP16 TP2 分别建库，在 page_size=128 下完成十九角色单卡原生对照；另有二十四组条件展开、两组给定耗时反馈及三项拒绝语义。原驱动末项因 P 文案断言停止于 47/48，实际拒绝正确，原失败与独立复核并列保留。条件展开不代替额外原生对照，也不授予连续区间或任意模型×TP 支持。

旧补丁推理镜像已删除；当前干净推理镜像已构建并取得 Qwen3-8B、TP1/2/4/8 的条件执行证据，PP、P/D 和 MoE/EP 也已有真实多卡来源及限定条件展开。完整同步协议、扩大的独立多卡结构对照和通信性能仍需各自验证。性能采样、成本建设及 MAPE < 6% 独立评价继续后置。

当前并行执行结构窗口已收齐重新全量独立调查和存储关联补执行；后续对来源机制、整窗口对应及stream完成关系取得限定开发证据，三个MoE/PP域共16项控制展开及Qwen3 TP2×PP4全部rank通过开发核对。原生输入条件下的KV局部变换、既有预测轨迹的请求/KV状态及原生请求进度已取得开发证据；原生控制工作范围已有声明及边界证据；KV发送的形状传播与逐请求槽位已在限定开发回归中修正，不同组批的跨调用/历史条件比较和重新冻结独立验证仍未闭合。goal运行中，S8尚未验收，调度优化与性能建设继续后置。
