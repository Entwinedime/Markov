## 现在的项目

`/home/markov` 延续原有 trace → DAG → 配置变换 → 成本绑定与执行流程；新实现已分离到 `/home/markov-rebuild`，`/home/markov-next` 是独立、只读参考的项目。三个项目不能混用完成状态，暂停的数据复制不自动恢复。

现有入口能够准备 base 和同源 CPU 校正、独立维护性能依据、预测一组 HiCache 配置，并在上层运行准确性实验或有限配置搜索。SGLang 是完整 HiCache 主线；KTransformers 保留 hook、manifest、原始 DAG 和仿真接入，尚无完整 GGUF 推理验收，不能称为同等性能覆盖。

当前时间与空间优化已在代表预测和同源整组核对成本/源共享、私有串行程序合并与按边界回调；完整预测仍慢于base正常运行，性能维护及跨批复用尚未完成，真机10倍目标未达标。

## 可用于比较的完整 HTTP 结果

10-22 从空数据恢复的实验完成了 33 份 base/CPU 输入、独立成本准备、186 格 cross 预测和 495 次有效正常测量。各条件五次实测取算术均值，不排除 gap、未归属成本或 Prefill/Decode。

| 面板 | 格数 | WAPE | P90 APE | 最大 APE |
| --- | ---: | ---: | ---: | ---: |
| 原 5 配置 × 3 负载，每个 base 预测其他配置 | 60 | 2.719% | 8.494% | 9.804% |
| 扩展配置与开发 ShareGPT | 72 | 2.666% | 3.627% | 18.785% |
| 未参与开发的确认负载 | 54 | 3.092% | 4.576% | 5.430% |
| 合计 | 186 | 2.826% | 4.576% | 18.785% |

185/186 格低于 10%，176/186 格低于 6%；最终为 `completed_with_model_limitations`，不是所有门槛通过。正常对照另有七次失败，含四次紧张 host 缓存下的 Prefill OOM、一次启动超时及两次 HCCL 端口冲突。成本覆盖仍为 partial，也没有全体 target 的结构证明。

这是带修复、补充独立测量和续跑的恢复结果，不是从空目录一次无人干预成功的证明。成绩来自当时程序，不能作为当前修改后的验证。依据为 [恢复结果](../data/reproductions/hicache/results.md) 及 [三面板评分](../data/reproductions/hicache/evaluation/)；预测输入使用独立成本包 `data/reproductions/hicache/costs/prediction_cost_model.json`。

18.785% 的大误差对应 C5 → 短超时写回 / W2。10-22 排查中，base self 与 target 的 Release 预测均为 8.181946 秒，轻量计时未重现旧慢样本，尚不能据此确定 CPU、I/O 或首次准备责任。带计时结果没有替换正常真值，该误差没有已验证的修复结论；保留 [排查证据](../data/modeling_runs/e2e-outlier-20261022-3Nxfsq/findings.md)。

## 搜索已经证明了什么

10-23—10-24 的展示在同一部署、容量及固定输入下，搜索两个负载各 72 个配置。W3 全部得到预测，ShareGPT 回访得到 68/72；四个短超时写回配置遇到设备页不足与主机备份拒绝，保持未知，不能从成功子集宣称全空间最优。

选定的 17 个配置×负载条件各测五次，共 85 份有效正常样本：

| 负载 | base 均值 | 预测首选的实测均值 | 缩短 | 已测 cross WAPE |
| --- | ---: | ---: | ---: | ---: |
| ShareGPT 回访 | 45.745 秒 | 29.331 秒 | 35.88% | 1.42% |
| W3 预取准入与回访 | 5.207 秒 | 4.550 秒 | 12.62% | 2.99% |

这说明等待与重算之间有可利用的取舍：best-effort 的重算增加，完整请求却更快。候选间部分样本范围重叠，尚不能判定稳定胜负；ShareGPT 首选也不是已测参照中的绝对最快。依据为 [搜索展示结果](../data/search_runs/hicache-demo-20261023/request_ownership/results.md)，不能将该子集成绩推广到未测页宽、容量、会话或平台。

10-25—10-27 的扩大自动寻优研究已按用户要求完全终止。期间出现 OOM，随后降低并发并增加资源上界，仍留下未完成实验；部分预测和采样不算研究完成。其后台任务、时限补全及旧待办不属于当前工作。

## 仍限制使用的地方

- **运行成本偏高。** 源读取与结构准备、大量目标工作、每格可变状态、尚未复用的跨批准备、性能库重复观测和完整采集产物仍放大时间及空间；成本包与纯查询已共享，不能再将逐格复制视为现行默认流程。
- **结构泛化有边界。** 仍使用源窗口内的部分调度检查机会；新的模型布局、调度方式、后端和特殊执行分支需要独立支持。结构报告覆盖有限，不能将全部成功执行等同于整图正确。
- **数值覆盖有边界。** CPU residual gap 和部分外围等待仍迁移源近似；独立模型存在范围外查询，常数或典型服务不能解释每次系统调度波动。
- **首次维护不够轻。** 新平台需要采样定义、工作变量、部署匹配及训练声明，空数据库不能自动产生全部成本；现有独立 runtime 提取主要服务 SGLang。
- **搜索结论有限。** 有限空间内的预测排名与小集合实测确认已经可用，任意配置、跨平台和带资源代价的完整自动寻优尚未完成。

当前先降低不改变建模意义的冗余，再在有明确误差边界下调整执行粒度；不通过重拟合 target 或删成本交换速度。是否扩大研究，应取决于运行成本、覆盖范围和真实可区分收益。
