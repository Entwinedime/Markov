### 计算配方与页几何

188 个计算帧中，134,044 次已解释原生调用归并为 74 种配方，展开为 191,760 个操作、57,716 条配方内部依赖；源变量重绑定全部一致，无缺失行数绑定。
覆盖原有线性、归一化、激活和注意力，并接入输入复制、嵌入及其掩码、Q/K reshape、位置编码、输出裁剪/转换和贪心采样。
输入复制保留原生 dtype 组首次出现的顺序；随 query 与 batch 变化的元素量分别绑定。输出掩码只使用 lookup 返回到 reduction 提交间的原生窗口，不重复绑定父调用中的子操作。
94 次 Decode 输出直通明确作为视图处理；Q/K reshape 按布局决定是否物化，源存储共享标记与规则一致。
注意力元数据准备、CPU 及完整跨流依赖仍未解释，当前不能称为完整计算帧。
一次调用可产生多个操作，不能继续把调用数与操作数混为一谈；内部依赖不等于完整目标图。

源 token 祖先关系共 26,133 个前缀。32/64/128-token 页各生成 47 请求、34 个非根 radix 分段，完整保留前缀需要 816/408/204 页。
三组均生成上述计算子集；客户端 drain_hicache 屏障位于第 35 个请求之后，不迁移源等待或 checkpoint 断言。
这是不淘汰、无 padding 的内容集合与工作量检查，不代表真实目标驻留、峰值容量或最终命中。

Cache 集中维护分段容量、引用、复制、发布和确认，分裂保留保护。有限两级缓存程序已按容量和写策略主动生成备份、回载及相应计算工作，成本缺口不改变合法动作。
此前 128-token 页的 D2H 域外已用独立测量补齐，write_back 三组页几何均完成 47 请求，证据在 data/rebuild/finite_cache_dma_covered/；其余旧两级结果保留在历史日志。
计算参与进程和写回备份批次以显式边汇合；回载在设备分配前保护主机来源，传输接管保护直至确认，后台工作不强制在每次请求末清空。
文件存储现可按声明容量淘汰键，先整理整批再逐页发布文件；查询按实际主机锚点和跳过设备前缀后的 token 链解析，而非默认完整 prompt 键。
预取分别维护读、复制、发布、控制接受与 worker 返回；停止后仍执行原生要求的一次被拒绝发布复制，缓冲区到实际返回后才归还。
wait_complete、best_effort、150 ms timeout 及补充的 75 ms timeout 各运行三种页几何，共 12 个组件情形均完成 47 请求并清空 I/O 队列；设备/主机/文件容量峰值未越界。

这些是对称参与进程、空初始文件存储和部分成本下的仿真。查询/准入及其他 CPU、完整跨流依赖和完整原生批次仍未验证，不输出 HTTP 耗时，也未独立对照 target 结构。

### 通信与计算的衔接

源 24,440 次参与者调用按组、成员和原生调用序号归并为 12,220 次通信。每个参与者的输入计算实际完成后登记到达，到齐后绑定一次共享服务，再释放后续计算；同一调用线程的后续帧也保持前后依赖。
所选独立模型测量的是“最后输入就绪到组内最晚完成”，因此不重复支付到齐前等待，也不从模型响应再扣一次偏斜；模型与系数未改。
32/64/128-token 几何各执行 188 帧、191,760 个计算服务和 12,220 个共享通信服务；三组有限缓存、文件预取及计算运行也均完成 47 请求，I/O 空闲且容量未越界。
证据在 data/rebuild/collective_verified/、collective_verified_geometry/；两进程各约 81 秒、峰值约 2.23 GiB，均只准备一次来源，原始图及源回放未变。

当前按参与组最晚完成统一释放各成员，未表示各成员提前完成的差异与到齐前网络占用。验证中设备响应对称且 CPU 尚缺，仿真到达偏斜均为零；不能宣称已验证非零偏斜或完整请求。
