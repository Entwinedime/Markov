## 目标工作与共同执行

### 已解释的计算调用

188 个源计算帧含 134,044 次已解释调用、74 种配方，展开为 191,760 个设备操作和 57,716 条配方内部依赖。源变量重绑定无差异，全部调用获得原生规则及唯一 caller/worker/device 关联。
线性、归一化、激活、注意力、输入复制、嵌入及掩码、Q/K reshape、位置编码、输出裁剪/转换与贪心采样均已进入共同调用过程。

框架适配器生成准备代码、原生提交及设备工作，共同编排器维护 caller、worker、设备的连续依赖；注意力准备后不再强制等全部设备工作结束才进入计算主体。
一次调用的多次设备发射共享一次提交和返回，例如采样的归约与类型转换；纯视图仍支付自己的 CPU 工作。派发延迟从提交与前一后台任务均完成后起算，不占服务资源。
同步读回先等生产者，再支付 API 自身服务及读回尾部，没有用父包络或设备墙钟补 CPU。

最终三种页大小各完成 188 帧、134,044 次调用、191,760 个设备服务、188 次 metadata 和 12,220 次共享通信。
每种几何共有 2,519,294 个原生计费操作，其中 metadata 为 13,348 个，派发延迟为 185,650 个。计费操作数包含 CPU 服务及残余区间，不等于原生调用数或设备操作数。
计算与缓存联合运行各完成 47 请求，I/O 最终空闲，设备、主机和文件容量未越界。
两个最终进程约 105.0/108.6 秒、峰值约 2.23/2.33 GiB，各只准备一次来源；它们包括读入、构图、回放及多个组件运行，不是完整预测时间或 10× 成绩。

额外 1-token 几何仍生成 6,912 个视图端口，但在 metadata.entry 的页大小/页表范围外停止；首个连续计算片段未提交，执行节点为零。旧版的“先执行 4 个设备服务再停止”是独立 metadata 片段时期的结果，不能套用于现行原子提交边界。

原生审查补上旋转位置编码表在多行时的两次连续化复制，并限制未解释的多 tensor 混合 dtype 复制与直接 Triton 发射。当前真实来源没有覆盖这些额外分支；它们只有静态机制与构建依据。
目前验证范围仍为既有资源放置、Ascend eager、单请求和已解释的阻塞通信路径；不包含 speculative/SWA/MLA、任意部署或跨流执行。

### 缓存、文件服务和通信

源 token 祖先关系含 26,133 个前缀；32/64/128-token 页各形成 47 请求和 34 个非根 radix 分段，全量前缀需 816/408/204 页。页身份与实际驻留、在途复制、发布状态分开。
有限两级缓存维护容量、引用、淘汰、备份、回载与确认；后台工作不在每请求末强制清空。客户端 drain_hicache 屏障在第 35 个请求后，等待由目标执行推导。
Ascend kernel_ascend/page_first_direct 在第 0 层传完整批所有层，不按层均摊虚构提前发布。

文件服务按整批整理、逐页读写/复制/发布、控制接受和 worker 返回执行；超时与取消使用同一时钟，停止后保留在途读取及一次被拒绝发布的复制，缓冲区到实际返回才归还。
此前 wait_complete、best_effort、150 ms 与 75 ms timeout 共 12 个组件情形通过，证据仍在 storage_wait/、storage_best_effort/、storage_timeout/、storage_partial/。
当前最终联合运行采用声明的 timeout。查询/准入暂为逻辑即时动作，因此 best_effort 的即时停止还不代表完整原生行为；文件阶段成本也不是逐段独立实测。

24,440 次参与者调用归并为 12,220 次共享通信，实际输入完成后登记到达，到齐后绑定一次服务，再释放后续工作。
独立模型表示最后输入就绪到组内最晚完成，不重复支付到齐前等待。各成员暂共享最晚完成时刻；本次对称参与者到达偏斜仍为零，非零偏斜及逐成员完成差异未验证。
