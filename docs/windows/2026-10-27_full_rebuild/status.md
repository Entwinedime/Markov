### 计算配方与页几何

188 个计算帧中，134,044 次已解释原生调用归并为 74 种配方，展开为 191,760 个操作、57,716 条配方内部依赖；源变量重绑定全部一致，无缺失行数绑定。

输入复制保留原生 dtype 组首次出现的顺序；随 query 与 batch 变化的元素量分别绑定。输出掩码只使用 lookup 返回到 reduction 提交间的原生窗口，不重复绑定父调用中的子操作。
94 次 Decode 输出直通明确作为视图处理；Q/K reshape 按布局决定是否物化，源存储共享标记与规则一致。
注意力准备现有独立原生调用程序；计算主体的 CPU、完整跨流依赖仍缺，当前不能称为完整计算帧。
一次调用可产生多个操作，不能继续把调用数与操作数混为一谈；内部依赖不等于完整目标图。

源 token 祖先关系共 26,133 个前缀。32/64/128-token 页各生成 47 请求、34 个非根 radix 分段，完整保留前缀需要 816/408/204 页。

Cache 集中维护分段容量、引用、复制、发布和确认，分裂保留保护。有限两级缓存程序已按容量和写策略主动生成备份、回载及相应计算工作，成本缺口不改变合法动作。

### 通信与计算的衔接

源 24,440 次参与者调用按组、成员和原生调用序号归并为 12,220 次通信。每个参与者的输入计算实际完成后登记到达，到齐后绑定一次共享服务，再释放后续计算；同一调用线程的后续帧也保持前后依赖。
所选独立模型测量的是“最后输入就绪到组内最晚完成”，因此不重复支付到齐前等待，也不从模型响应再扣一次偏斜；模型与系数未改。

当前按参与组最晚完成统一释放各成员，未表示各成员提前完成的差异与到齐前网络占用。验证中响应对称且计算主体/请求 CPU 尚缺，仿真到达偏斜均为零；不能宣称已验证非零偏斜或完整请求。

### 注意力准备与共同原生调用

SGLang 适配器按目标 context 和页大小生成 max、同步读回、页表索引、除法/类型转换及外围 CPU 工作；共同编排器连接 caller、worker 和设备，不读取成本系数。
caller 返回可与后台/设备执行重叠；派发延迟在提交和前一后台任务完成后开始，不占服务资源。同步读回先等待生产者，再支付 ACL API 和同步后的复制/返回，各段没有重复收费。
支持范围为当前 Ascend eager、单请求、非 speculative/SWA/MLA 路径；metadata 与设备计算主体暂用完成边界衔接，主体 CPU 的重叠尚未表达。
