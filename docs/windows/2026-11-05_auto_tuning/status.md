## 审查与限制

本阶段业务源码和 C++ 未改；新增固定条件确认例子复用 DeviceTask 和 normal_statistics，实际运行了三次初测、按原规则追加、已有 baseline 复用和报告分离。Ruff/格式及公开报告检查通过，前阶段 Docker Release/Debug、KTransformers 三种预测、显式回放和独立评价继续适用；未作新的 KTransformers 设备采集或精度验收。

新七条件有两个 self、五个 cross；另一 base 的四个评分共享正常观察，不增加独立条件数。限时预取代表在两个请求上仍有工作差异；API 命中/回载核对不证明全部内部依赖。WAPE 3.120% 略高于项目 3% 评价目标；原 C3/w3 三次参考仍有五格不达标、最高 12.221%，不由新结果覆盖。

回访收益主要与首次准备规格有关：模型关键路径的 Prefill 输入准备为基准 13.455 sec、推荐 0.040 sec，正常慢请求与相应标记一致，但未直接分测内部编译。已有 prepared 条件的预测排序反转，未经正常实测，不能称长期稳态收益。

空库旁路全来自自己的独立事实，与正式 39 类选择隔离；35 类仅覆盖该开发输入所需工作，没有新的正常精度认证。42.05 分钟为两次实际工作流内部时间之和，含失败和恢复，不是连续一次成功 CLI；首次外层总墙钟未单独计，恢复与复用命令另有真实墙钟。保留量不是临时峰值，资源观察只有部分容器生命周期样本。未验证任意硬件/带宽、吞吐/P99、完整空间真实排名及旧工程 10×。
