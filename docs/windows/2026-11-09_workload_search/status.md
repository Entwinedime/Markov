## 限制

ShareGPT 是固定历史的串行回放，BurstGPT 只保留公开记录的长度配对和顺序，正文为独立 token；人工负载为受控前缀序列。三者均不证明真实突发、高并发或长期稳态。

使用 semantic 来源，没有完整低层静态回放资格。正常评分不扣 gap、未归属成本、Prefill/Decode；首次使用、小输出近似、源控制残余、暖文件响应及竞争仍有不确定性。采样覆盖与预测成功不能代替正常精度。

四项归一化费用仅计 device/host 存储及两条固定参考链路，48/64 GiB 固定存储是预留假设，非实测峰值；文件缓存可回收，不将容器当前总用量当固定需求。不计 CPU、整卡算力租价、SSD 容量或流量费，不声称真实账单或带宽寻优。第三次重复和额外搜索不挤占最低实测及交付。
