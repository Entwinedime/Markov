## 2. 当前实现边界

Python应用管理正式任务和进程，框架/runtime适配提供原生事实；C++生产共享定义、布局、执行模式及角色绑定，再按目标参数展开。serving经共同接口推进控制、资源和执行，实验编排与独立评价在example。

原生控制持有请求逻辑；核心独占槽位、页及前缀树，执行器维护模拟时钟和在途完成。轻量与原生控制共用这些接口，各自合法组批，不保证批次相同。节点耗时使用显式给定值，没有实测成本模型或精度结论。

同库主要复用请求、成员、到达、并发和KV容量变化；模型、TP/PP/EP、dtype、attention backend、page_size及机制域分别建来源。EP使用给定路由与padding条件，不声称预测真实权重下的自然路由。缓存目前为一级；PD只在Prefill侧缓存，Decode仍接收KV。overlap、speculative和多机尚未正式支持；具名MoE mixed的原生拒绝继续保留。
