## 2. 当前职责与能力边界

Python应用管理任务、累计费用和进程；框架/runtime提供原生事实，解释与模板生产在独立工作区交接。C++生产共享定义、布局、执行模式和角色绑定，按目标参数展开；实验编排和评价在example。原生控制持有请求逻辑，核心独占槽位、页和前缀树，执行器维护模拟时钟和在途完成。

ServingWorkflow经ExecutionFeedback接收发布/完成。普通执行按给定节点耗时推进，开发旁路由ObservedFeedback消费真实边界时间；控制、资源和构图共用业务链。旁路不提供批次、分配或图答案；内部节点计时和真实设备消费者完成仍未测量。

同库主要复用请求、成员、到达、并发及KV容量变化；模型、TP/PP/EP、dtype、backend、page_size和机制域分别建来源。EP使用给定路由/padding；缓存目前一级，PD只在P侧缓存。overlap、speculative及多机未正式支持，原生不支持的MoE mixed保留拒绝；没有实测成本模型或精度结论。
