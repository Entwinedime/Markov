# 三类既有负载的全量离线搜索

开始日期：2026-11-10。

目标：复用 ShareGPT 512、BurstGPT 长度回放 256、程序生成 1,200 条请求的既有 base，按现行资源空间与报价完成全量预测，报告配置取舍和实际搜索开销。

## 范围

- 请求内容、顺序、准备边界及输出设置保持原实验不变：前两组输出上限 16 tokens，程序生成固定 8 tokens，各另有 8 条准备请求。
- 使用当前 8 个资源套餐与全部 162 种策略，每组 1,296 点，三组共 3,888 点；按三级预留容量及四向带宽七项计价。
- 采用现行共享独立模型和资源实现，整轮固定选择；报价、套餐及参考带宽从实际声明读取，不按收益改值。
- 只运行 CPU 预测，不新增 base、校准、正常实测或设备任务；缺成本、不支持与不可部署保留原因。
- 与另一个长文档窗口独立输出，不修改其输入、状态、任务或结果。本轮不改 PPT。

## 执行步骤

1. **固定输入与运行依据。** 核对三份 manifest 与原请求一致，记录现行代码基线、必要差异、配置和模型。核对每组配置唯一性及七项计费，确认预测不挂载正常真值。先用首批核对成本域、内存和输出，再估算完整运行时长。
2. **完整枚举。** 沿现有预测入口分批执行，先按每批 48 点、最多两个各 8 GiB 的预测进程组织；检查其他任务占用，保留至少 20% 主机内存余量。复用完成批次，保留失败、累计时间和进程句柄；缺口不触发自动补采，不用抽样替代全空间。
3. **汇总与交付。** 按当前基准配置的费用上限，列出最好和最差预测配置；同时保存完整候选分布、时间—费用 Pareto、七项报价、覆盖状态、墙钟、最大 RSS 和保留量。核对配置、成本与报告，完成相关文档检查及本窗口分层提交推送。

## 完成判据与限制

- 三组均列齐 1,296 个唯一配置；成功、不可部署、缺成本、不支持、失败分别计数。存在未解决的缺成本、失败或超时，就保留覆盖不完整结论。
- 最好、最差来自部署合法、预测成功且费用不高于当前基准的同一集合；并列情况保留，不为结果好看改排名规则。
- 结果写入 `data/workload_full_scan_current_20261111/`，逐批可恢复；不覆盖旧 96 点结果，也不删除历史资产。
- 原实验的 3×96 为固定种子随机抽样。本轮空间、报价和模型均有变化，旧结果只作历史背景，不能直接用于量化同条件搜索方法收益。
- 新推荐只报告预测收益。历史正常结果仅在配置、资源与初始条件一致时用于评分；不据此宣称全空间精度或真实最优。
- 已有 base 对新增资源路径的依据、失败回载等成本域及全量时间和空间开销仍需首批确认；不足时记录具体缺口，不暗中扩充设备运行。
