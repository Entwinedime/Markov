## 独立 CPU 与传输交接

一个 CPU 组含双请求、单请求和空调度配方，各三次重复并附停写记录对照。取得 345,216 条有效区间、1,936 个特征点；当时计划的 488 个请求特征均有覆盖。54 个低于校准分辨率的区间保留排除记录。同步传输产生 5 个候选，没有另开设备采样。

公开恢复查询 CPU/传输后，正式结果仍为 needs_data，缺设备成本未填零。真实 CPU、部分真实传输加显式给定设备耗时的条件运行完成 2 批，28,274 个 CPU 服务采用实测候选；不能称为全实测闭环。

活动记录相对停写记录的窗口中位比为 1.2165，但停写对照仍安装全局回调。这不是无插桩基线，也不是预测误差；低扰动和 SDK 内部就绪近似仍未取得资格。

样本表示整理后，压缩体积从 13,563,638 降至 11,429,253 字节，1,936 CPU 与 5 传输候选的样本数、中位数和范围保持一致。原 CPU journal 已消费并释放，保留规范样本与校准/边界事实；这是重编码/重拟合，不是新的原生采集。
