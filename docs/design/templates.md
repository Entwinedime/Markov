# 公共图与子图模板合同

模板把原生执行取得的操作、数据和状态关系变为可求值的结构。语义层次决定如何组织工作，物理实现与测量边界决定怎样执行和计费，两种粒度分别维护。

## 实现域与来源

模型及 dtype、框架/环境、attention backend、逻辑并行布局和影响实现的硬件条件共同约束来源。目标必须匹配已有参数关系和实现条件；缺少必要关系、原型或状态语义时，补充相应来源或适配，不按配置名称断言永久不可变换。卡号、部署路径、本次 workload 名称和镜像标签不构成模板类型，实际实现内容另行判断。

请求数、长度、到达和池容量作为目标参数或状态处理。其引发的实际分支需要原生条件和相应来源，不从少量样本拟合结构阈值。代表采集由 workflow 选择，框架 adapter 提供原生会话、机制入口和可触发条件；启动、预热、观察、后处理、失败和存储计入同一任务预算。

一次代表采集建立的是包含必要局部原型的模板库。目标可改变参数、按规则重复与重连已有区域，并选择已声明的有限分支；来源未逐项执行过的目标实例不必逐项重采。固定模型维度、页布局或角色绑定尚未参数化时，当前库不能自行跨越这一边界；共同表达式机制存在也不代表相应适配已经完成。

统一预热建立已加载且所声明路径准备完成的起点。逻辑 KV、workspace 和通信资源各有初态，不能用一次来源的状态替代任意目标容量或实现的初态。运行时可按原生实现的可证明上界预留资源，发布实际建立的容量下界和适用域；目标遵循同一初始化约定，窗口内不变的资源无需另建可变状态机。

## 观察与公开来源图

原生模块目录和调用范围提供层次，算子分派及明确原生接口提供工作实体，框架边界提供 batch、请求、槽位及状态含义。原生框架拥有采集时的请求、KV 和 worker；公共观察器不维护第二份原生状态机。

观察记录保留值身份、出生几何、存储、版本及读写。Tensor 身份与存储生命周期分开；view 保留别名，修改产生新值版本，地址复用不能串接已经结束的对象。

已经在 CPU 上物化的状态结果可以作为 `observed_result` 留在原始调用记录，例如原生 unique 返回的释放页号。它只供追溯和独立状态核对，不进入共享定义或目标默认值；观察器不为取得它额外复制设备 Tensor。

公开投影保留普通操作，将原生接口内部工作折叠到声明端口。接口私有中间值不能未声明地逸出；输入、返回值、修改后的值和内部捕获的状态资源均参与数据与存储连接。公开 Tensor 有可求值几何，私有资源可以保留不透明几何及明确读写。

数据依赖和存储 RAW/WAR/WAW 共用一套算法。全存储保守顺序与精确逻辑页所有权分别表达；前者不证明已恢复任意访问区间。HostRead 保留可见协调边界，不能被整体接口吞掉。

设备标量参与切片或赋值时，外层接口保留为透明区域，HostRead 及其后的原生视图分别进入公开图。视图偏移由实际原生偏移和参数公式核对；整缓冲区写回别名必须对应实际写入输出的同一存储及版本，不通过重新标号或隐藏标量协调制造纯视图接口。

## 参数关系与输入集合

框架将实际输入轴、batch 字段及必要标量绑定到语义来源，固定模型维度来自真实模块、参数和分片。生产侧复用原生 fake/meta 能力并局部补充关系；C++ 编译、求值和装配，不再维护另一套算子形状解释器。

view/reshape 的维度优先沿实际 Size 身份或调用位置的有限元数据表达式恢复。张量身份确定 shape/size 的来源；单次赋值的局部尺寸在实际元数据读取时保存关系，未修改形参沿真实调用参数取得来源，固定模块属性提供模型维度。只改变元数据推导参数，不事后重读已变形或重绑的张量来猜局部值。失去来源的变量保持缺口，不按数值匹配或重放 Python 控制流补齐。索引赋值剥离前导单轴等真实 binding 规则由共同 runtime 声明条件，与后端布局条件组合，不按 kernel 名字选择实现。

数据相关标量由提供者声明语义及有效范围，runtime 以产生它的 Tensor 身份连接原生索引，只向 fake/meta 参数交出表达式，真实读回和操作保持原样。符号步长与形状共同约束布局，单轴退化、空与连续条件分别表达；来源解释重算自己生成的条件，不覆盖其他组件的原生条件。区域与公开操作的选择条件均须在来源点核对。

相同观察整数不表示相同语义。已出生值的关系保持原义，后续接口声明作为该作用域的约束；callee 的临时绑定在返回或异常时恢复。缺失关系保留为生产缺口，不猜成常量或用目标数据补齐。

具名输入端口的直接命名轴可以从调用方实际值的几何取得，模板入口和子调用使用同一绑定规则。已经给定的参数及复合维度仍作为约束，不覆盖请求语义，也不反解或拟合方程。跨 stage 交接消费实际产生的分片，不统一假设它具有完整批次的 token 数。

持久缓冲区的容量关系在每次形状环境建立后、原生首次读写前声明，随后各写入值版本继承同一含义。声明来自原生构造器和实际容量；不能晚到某个消费者才修正整池几何，造成准备与模型端口不一致。

构造器的动态几何由所属调用和已声明的数据容器提供，作用域退出后恢复原来的绑定。框架已有缓冲区注册表时，复用其槽位轴和形状函数生成视图关系；底层存储保留资源身份，公开视图保留目标几何与别名。目标资源容量和初态由执行装配提供，视图可求值本身不授予容量资格。普通原地写入的返回别名沿用目标张量几何，改变形状或布局的原地视图继续使用对应原生语义。

只为张量输出推导输出几何。无张量返回的调用仍根据原生 schema 保留状态写入及必要依赖。数据相关输出长度由明确的目标状态或输入关系给出，不能仅从输入 shape 猜测。

只读 Tensor 列表通过输入集合表达：

| 内容 | 负责方 |
| --- | --- |
| 元素 dtype、device、几何及数量/求和关系 | 模板合同 |
| 来源成员和原生调用位置 | 观察证据与调用绑定 |
| 目标成员参数、实际值和资源 | 目标控制与装配 |
| 元素端口、汇总量及数据依赖 | 公共实例化 |

共享自身定义不保存来源成员数量。父子区域可显式传递同一组值和参数；来源中的固定端口绑定则保留其原有范围。不能把组成员静默放回固定槽位，或把可变端口解释为任意循环已能生成。成员生产、逐项访问、修改、物理布局和跨批连接各需相应规则。

父区域内部产生的值集合由子区域从实际目标几何恢复成员参数，不让调用方再填写同一事实。恢复只支持元素合同中明确命名的轴，其余维度继续核对；复合关系不做方程拟合。固定来源成员数与目标要求不符时形成布局不匹配，不能自动补出新的生产调用。

有明确原生依据的集合形成另行声明次数及元素来源：重复引用保留同一值和存储；独立生产则重复一个无外部输入、无状态效果、单输出的闭合操作模板，每次分配新的值和资源。次数在调用方参数中求值，不从来源整数相等推断。生产原型须紧邻集合消费者、具有相同定义和固定绑定，成员不能逸出；带输入、逐成员状态或索引变化的循环需要相应关系，不由这一规则自动获得。

有输入或状态的原生循环使用有序子调用：定义声明 `call_role` 及 `call_count`，目标调用提供 `sequences` 中的成员参数；共同实例化按次序选择满足条件及具名端口签名的被调入口，连接输入/输出并保留每个成员的真实工作。目标不指定子实现名称，适配器只提供原生顺序和参数。普通父调用可声明 `call_family`，通过同一接口选择已有分支；次数不符、缺入口或递归循环在发布前拒绝。成员体可共享，来源成员数不生成新的父定义。

目标参数可以按已有角色绑定索引，例如模型层对应各自的专家工作量；公共实例化在引入该绑定的调用处应用参数，并向子调用传递。它不依赖来源布局的子调用路径，也不让核心识别框架层名；参数的业务含义及来源由 adapter 维护，角色身份不能在选择另一原型时丢失。

集合数量和汇总量由目标成员计算，调用者已提供的数值必须一致。状态型区域从前态和真实工作量推导后态，派生后态不能由目标覆盖；不同页数来自实际页所有权，不能只按 token 数估计。

## 共享定义、布局与调用

归一化分开三种内容：

| 内容 | 保存 |
| --- | --- |
| 自身定义 | 区域自身操作、类型、参数关系、条件、状态效果与局部值 |
| 组合布局 | 子调用、端口、值/资源别名及固定或集合绑定 |
| 调用证据 | 层号、rank、固定数值操作数、来源参数、实际成员、子调用和原生出处 |

父区域引用子区域并拥有自己的剩余工作。重复层共享自身定义，权重、层号和 KV 绑定留在调用中；子调用数量变化不复制父定义。组合布局与自身定义分别共享、分别计数。

同一来源域的正式模板文件由一个 `catalog` 和多个 `roles` 组成。catalog 共享自身定义、组合布局及执行模式，生产时共同归并，消费时只解析一次；每个角色保留自己的实现身份、覆盖事实、入口、固定值及执行资源绑定。共享定义或模式不合并各 rank 的权重、KV、stream、事件或 CPU 资源，也不自动授予成本数据共享资格。

子调用布局使用 catalog 内统一编号，角色入口和执行变体仍从本角色的调用绑定解析。公共目录检查布局合同，角色检查自身可达调用和入口；不能要求 peer 具有另一个角色才会发布的入口，也不能因共享而遗漏本角色的必要调用。

等价 worker 可以用代表角色和显式绑定派生。正式 `roles` 中的派生项只保存 `representative`、目标角色元数据和绑定表达式，引用实际观察过的角色；公共读取先解析来源，再在私有调用绑定中求值，不修改共享 catalog、原始调用或 trace。绑定必须已有明确声明，不能按整数相等替换固定操作数；各实例的权重、KV 和执行资源保持独立。结果的 `role_source` 区分实际观察与派生映射，代表来源的完整归属不表示派生 worker 已获得独立原生对照。

普通操作参数树中的固定数值按出现位置保存到调用的 `literals`，共享操作引用相应槽位；例如词表分片起止值不复制整份 embedding 定义。槽位分别保留原值和数值类型，不根据数值相同推断语义相同，也不作为目标可调参数。shape/scalar 等已声明的表达式、固定几何、读写和工作顺序仍参与定义；这种归并不自动推导新形状、分支或跨 TP 资格。独立生产集合只有固定绑定、数值操作数和执行效果均相同才能重复同一原型。

编译时的原始执行观察只保存在来源捕获中。正式模板发布已编译的执行模式和调用绑定，不再次内嵌相同的原生任务/API 记录；入口仍保留来源区域、调用路径和 batch 证据，追溯不要求复制整份观察。

共享身份保留实际操作、固定几何、必要别名、参数规则、条件和状态效果。调用 ID、绝对时间、设备号和动态取值不进入定义；同名、同类或同 shape 均不足以证明可合并。归一化采用确定的规范化，不开发任意图同构或数学等价证明系统。

区域入口提供角色、阶段和既定类型合同。来源选择与共享定义是不同职责；跨阶段或不同类型复用须有明确的调用及状态依据，不能因内部操作相同而混用入口。

入口是否依赖阶段由适配器按原生行为声明。阶段无关的状态操作使用显式 null 阶段，不能从“采集时恰好属于 Decode”推断只能用于 Decode；未声明时保留来源阶段，不使用自动跨阶段回退。

## 目标实例与状态

目标控制器拥有请求、成员、槽位和逻辑 KV；执行侧拥有资源前沿、会变化的运行时资源及模拟时间。初始化保证的不变量随资产交接，模板声明访问和效果，不拥有控制状态，不引入框架私有调度器。

实例化依据目标参数和条件选择来源，求值几何、物化调用与集合端口，再连接值与存储依赖。来源动态参数和后态只用于核对，不能作为目标默认值。固定模型/层绑定与目标动态状态分别交接。

区域以命名值端口连接。前一区域的输出直接成为后一区域的输入，核对 dtype、device 和已有几何；写入后的新值版本与其底层存储身份分开。状态效果同时交出标量前后态和对应输出值，控制状态提交与设备数据就绪分别处理。

可确定的控制向量另带整数内容，如成员长度、槽位、KV 位置和空闲页；连续整数用起点与长度区间表示，避免逐 token 展开。绑定时核对一维几何及同一值的已有内容，集合入口公开成员值身份。已知内容只是目标事实，不消去原有生产者、HostRead、搬运或依赖；边界内容已确定也不证明内部准备及资源执行完整。原生索引编码留在框架适配，公共图不识别框架、模型或 kernel 名称。

延后完成的通信工作继承实际发送调用的参数、固定绑定及实现条件。完整 payload 和线上分片分别表达；不同完整 payload 可能产生相同 wire shape，不能仅按 wire shape 选择等待模板或连接完成事件。批次、消息通道与张量字段提供实际原生工作身份，源码协议变化由框架适配器解释。

同一资产和目标 rank 内，观察前已存在的存储通过来源绑定保持共享，原生调用新产生的存储每次实例化都独立分配。生产端在公开 producer 与私有资源归属确定后判定存储出生；来源身份只留在调用绑定，不进入共享定义或布局。显式输入端口优先绑定当前状态值，例如拼接更新后的页池可以换到新存储，不能继续套用来源初态。

候选区域先核对参数条件、命名输入的几何与别名，再并入目标图；不匹配时选择其他已有候选，不能先修改目标状态。状态变化在规定的逻辑完成端口提交，由唯一状态所有者负责；区域装配本身不提交控制状态，也不证明目标资源容量及物理执行已经成立。

到达、组批、准备、模型工作、内部结果处理及请求输出具有不同端口。ResultProcessed 推进生成/结束效果，RequestOutput 提供 token 可见时刻，二者不互相代替。控制器根据实际模拟完成事件生成后续 batch。

P/D 实例各自复用本地角色装配，共享全局图但保持独立状态与资源。KV 来源保存原生注册的层、K/V 类别、head 区间、每 token/head 字节、页及辅助数据布局；交接连接这些区间的实际重叠，每个目标 head 须有唯一来源。原生整 buffer 复制与逐 buffer/token 切片分别保留实际调用分组，不用总字节相等代替分片关系。每对端点的 metadata 确认等待其 KV 复制；接收与释放消费各自端点的完成条件，不额外增加全 world 屏障。

PD 的池和交接效果在本次提交片段排空后提交，交接就绪分别保留相关 rank 的 CPU 返回与设备/通信尾部；CPU API 返回不能单独代替 KV 的设备就绪。批次列按当前原生状态交接，prebuilt 等状态可以没有 token 张量；模板的输入/输出端口表达这种存在性，目标视图保留当前实际列，不将全部候选列都强制为必需。

## 物理执行与 CPU

操作到设备任务的关联依据原生调用、队列、connection、task/event 及明确范围；时间邻近不能产生所有权或依赖。一项物理工作只有一个执行归属，父子和整体/内部工作不能重复计费。

设备工作可以作为参数化局部图，或作为有完整外部接口的整体服务。整体化须保留跨资源作用、中间就绪和释放关系；单 stream 本身不足以证明可以整体计费。执行粒度在生产时确定，不能因缺少成本而临时改用父区域总时长。

CPU 按调度、准备、必要提交和发布等稳定服务组织。路径变化由成员、状态及原生分支重组，服务时长由独立性能采样取得。保留提交、等待及发布切口，等待由依赖产生，观察器开销不进入业务服务，不能叠加整段 run_batch 墙钟和设备成本。

归属摘要分别表达未观察、部分归属和全部归属。全部归属只证明任务有公开所有者；资源顺序、读写、目标实现与测量资格需要各自依据。来源时长不进入结构共享身份，也不自动成为成本资产。

设备任务和 CPU runtime 作用分别保留归属。搬运、等待可能只有 API 记录，没有设备 task；原生队列项的关联编号也不是 stream 身份。API 参数观察单独说明覆盖程度，来源调用可保留设备、stream、方向和字节数；这些来源值不能直接作为目标资源绑定或成本。未取得参数或语义依据的等待仍保留缺口。

原生同步搬运接口没有公开设备 task 时，runtime adapter 可依据实际调用/返回声明包含阻塞完成的单一服务，保留字节、分段及来源依据；不伪造 profiler 提交或设备节点。跨实例消费和复用等待该服务的完成。统一预热后排空的起点可显式声明初始空 stream/thread；此条件只处理起点之前的排空等待，不替代事件信号、通信伙伴或窗口内生产者。

## 适配与使用边界

公共核心维护表达式、集合、投影、归一化、绑定及依赖算法。框架 adapter 提供 batch/状态来源、原生组件接口与组合依据；runtime adapter 提供操作、形状及物理关联；必要模型家族声明只补充不能从真实对象取得的角色。

单卡分片来源保留本地布局、角色职责和逻辑通信，辅助传输与真实本地工作分开。真实多 rank 因果、通信时延和争用另需资格，不能从单卡替代推出。

支持判断沿同一实例化合同进行。缺原型、缺规则和缺成本分别交接，不维护逐 workload 黑名单，不以最近来源、空结果或零成本伪装完整支持。独立验收固定资产和规则，使用后续目标修正规则后须重新明确留出范围。

目标入口、所有必要操作数/几何、子调用与实现条件以及状态/资源接口均须可求值、可连接。无法仅凭已有输入确定的内容需要额外事实，原生不接受的配置则属于非法目标。当前表达能力、实际原生支持与已经取得独立证据的点分别报告，不能把某次拒绝或有限验证写成整个配置空间的理论结论。
