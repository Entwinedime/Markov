- base 只迁移对应且未变工作的成本；变化或新增操作使用独立测量与离线模型。缺测、结构不支持和执行失败分别报告，不填零。
- 同源 full/light 配对修正 CPU 采集开销；共享控制测量使用自己的配对，不能套用另一份 base 的时间坐标。
- I/O 按实际缺少的 DMA、预取或新旧页写入服务选择采样；部署元数据不是实测参数。采集串行，失败、重试和无效输出也计入累计预算。
- SGLang 与 KTransformers 共用 manifest、source DAG 和仿真；HiCache 只适用于 SGLang。NodeScale 默认关闭，现行规则的显式静态成本回放仍保留。
- 实验报告分别检查源回放、目标结构和完整 HTTP 精度；应用预测不需要 target 真值，评分不能触发训练或补采。

### 独立测量的依据与保留范围

使用历史数据时，以下边界仍然适用：

- 源 CPU 成本只校正一次；已绑定执行成本不再次扣开销。原始回放使用未校正源图，不能与正常 HTTP 精度混淆。
- 调用 shape、布局及模型角色由真实元数据和框架执行规则建立。父成本拆成子启动后，不再叠加父设备总时长。
- 设备与主机时钟仍有矛盾，固定偏移不能解决全部样本。依赖足以证明读回结构，不一定足以提取无等待的返回服务；不自洽样本不用于该口径训练。
- 空闲流原语约 1.70–1.77 微秒的服务不证明阻塞唤醒或争用成本。物理速率也不代表真实推理中的全部争用。
- 设备观测保留亚微秒精度；整数微秒仿真有量化误差，但量化为零不等于缺失填零。
- 重复入库不增加样本权重；按采集替换派生观测时保留原始 trace 和配对来源，已导出的成本包不会自动改变。
- 模型数按操作、实现和计时口径拆分，不是采集次数或物理机制数。包就绪也不表示任意目标已得到成本覆盖。

现行参数的来源以共享包的 `training_sources`、`training_source_manifests` 和实际 manifest 为准。
旧数据库副本及小成本包已清理；当前数据库和最新共享包在
`hicache_generalization_20261010/`。完整/轻量测量、CPU 成本和静态回放输入的保留范围见下方资产表。

## 接下来仍需解决

1. **等待与运行波动。** 一部分残余等待仍沿用 base，不能认为换配置后一定不变。
   留出确认中短超时多轮的五次正常运行跨度达到均值的 14.573%；对均值的预测误差小，
   不代表每次运行都准。后续先区分可解释的依赖等待、资源争用和暂时无法解释的波动，不统一缩放 gap。
2. **成本覆盖。** 这轮已补充短上下文、小页写入、批量确认、多节点回载和单页索引的独立数据，
   但变量各自有测量，不等于所有变量组合都测过。小向量和通信错峰的显式外推、I/O 的页宽端点近似仍有边界；
   物理传输速率也不能代表真实推理中的全部争用。partial 是限制提示，不是逐操作覆盖率或精度保证。
3. **结构证明。** 已修正错误主机等待、因果尾部裁剪和缺失连接编号关联，代表工作量也有对照。
   未对应工作、CPU 跨 rank 观测不对称、末尾发布和短 timeout 状态差异仍不能由低 E2E 误差证明正确。
   下一步应先提高这些关键语义的可观测性，再判断是生成规则还是计时近似的问题。
4. **应用成本与恢复。** base、同源 CPU 校正及共享成本包已能走完本轮预测；正常 target 实测只用于验收。
   仍需评估首次准备、失败恢复和离线建模的实际使用成本。已有采集账本没有同口径的逐目标完整 profiling
   实测对照，也未覆盖全部历史成本，不能宣称整套方法已证明更省。
5. **更宽的泛化范围。** 这轮已加入真实对话、六个新配置和两个不同 base，但仍固定 Qwen3-32B、TP=2、
   当前 SGLang/Ascend、串行请求及受控短输出。换模型、TP、并发、自然结束和其他后端应分别扩展执行规则与成本证据。
   KTransformers 的完整模型验证单列，不把本轮 HiCache 结果外推到它。
6. **实现简化与自动寻优。** 继续围绕实际数据生产/消费链减少重复表示，精度变化与纯重构分开验证。
   自动寻优尚未验收；应先确认预测对配置收益排序的可靠范围，再设计搜索空间和少量实测确认。

原总体及逐 base WAPE ≤3%、P90 ≤5% 的验收目标不变，争取所有格低于 6%。
