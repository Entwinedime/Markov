## 3. 保持的支持边界

- 主线为固定 Qwen3 dense / SGLang / Ascend TP2 和声明部署，FCFS、cold KV、统一预热；无 prefix cache、overlap、graph、mixed 和 chunk。
- 请求池、Prefill 预算及请求变化仅在模板和有限规则共同允许的域内使用；结构支持和性能样本覆盖分别判定。
- 五类流程 block 与模型内部区域表达语义，性能单元可以更细。共同核心消费统一模板和工作特征，不解释原生函数、kernel 名或框架专属配置。
- **当前实现**仍排除 host 控制、准备、提交与完成处理的 CPU 服务耗时；必要状态、因果和端口保留。当前专项将其作为待设计和实施的稳态成本范围，尚未获得 CPU 精度资格。计算、通信、实际数据搬运与设备命令继续计时，包括同步 host 复制。
- HTTP、tokenization、初始化/预热及模板外服务不计入 modeled 预测。原生端口窗口含不同范围的时间，不能直接把全部差值归因于某类成本。
- 独立验证不进入模板、拟合或调参。跨模型/TP/backend、KT 预测、原生控制器和更复杂成本模型属于后续能力。

详细合同分别在[采集](../redesign/04_collection_templates.md)、[语义](../redesign/05_controller_semantics.md)、[性能](../redesign/06_performance_execution.md)维护，不在计划重复机制全文。
