## 已收束的分析，不重复开展

- 加载成本：优先可辨识的 base 操作，clone 后缀只执行一次，base 与共享导出复用 C++ 拆分。
  收益有限，不能按单格成绩切换成本来源。证据：`clone_suffix`、`base_submission`、`full60`。
- worker 日志：可选测量及节点/就绪延迟校正已接通。同源开关使原始 DAG 少 55 微秒、
  自身预测少 232 微秒，cross 不变；不再为这个假设扩大补采。证据：`hook_emission/C3_w3`。
- 通信依赖：770 轮“不完整”包含 761 轮已被替换的源提交；16 处前驱不唯一属于已重建边界。
  不能据摘要数量删除等待或重复重建。证据：`hook_emission/C3_w3/collective_audit_findings.md`。
- 正常波动：C3/C2/C3 的独立复验为 5.267/5.273/5.084 秒，工作量核对一致。
  新旧评分分别保留；两次样本范围不是置信区间，更低总误差可能来自正负抵消。
  这些测量仅用于评分，不进入模型。证据：`normal_repeatability`。
- CPU 配对：对同 rank、同等待调用序列的 pending 分支估计单轮增量，不配对循环总数，
  保留源内变化。CPU 扣减量不等于 HTTP 收益。证据：`pending_scheduler`。
- 轻量 I/O：一次同 base 轻量运行匹配 87 个请求和 16 次预取，现有配对文件显式传递
  `reference_io`。固定 CPU 对照证实来源变化会影响预测，但新旧真值下收益不一致。
  保留单页宽外推与未测扰动限制。证据：`io_service_light`、`io_reference`。
